# من قتله؟ / Who Killed Him?

An asymmetric co-op detective game for 2 players communicating via voice call. Victorian London, 1890s.

One player is the **Field Detective** at the crime scene — examining rooms, reading observations, choosing what to describe. The other is the **Case Analyst** with the reference archive and suspect dossiers — interpreting findings and guiding the investigation.

There are no codes to enter, no buttons to "unlock" evidence. The conversation IS the game.

---

## Quick Start

```bash
cd client
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`). Both players open the same URL on their own devices and select their roles.

## How to Play

### Setup
1. Both players open the game on separate devices
2. **Player 1** selects **Field Detective**
3. **Player 2** selects **Case Analyst**
4. Both choose a detective name and select the same case
5. Start a voice call (Discord, phone, whatever works)

### The Field Detective
- You see the **crime scene** — rooms, clues, characters
- Read the **sensory observations** carefully: colours, smells, positions, textures, sounds
- Not every detail matters — some are atmospheric, some are misleading
- **Describe what you find in your own words** to your partner
- Approach characters and read their statements
- Use the **Case Notes** pad to record what you learn
- When ready, file an **arrest warrant** with your accusation

### The Case Analyst
- You see the **case files** — archive entries, suspect dossiers, documents
- Your partner describes what they see — **you search the archive** for matches
- The archive uses **tag-based search**: describe what you heard and find the reference
- Read the **suspect dossiers** — psychological profiles, backgrounds, alibis
- Review the **documents** — the post-mortem report, the will, the tea service log, the charity register
- On the **Case Board**, link clues your partner examined to suspects to build your theory
- When you have enough connections, file an **arrest warrant**

### Winning
- Both players must agree on the accusation
- Sign the warrant and see if you identified the correct killer
- The **Case Summary** reveals the full story and solution

## Features

- **Full Arabic support** — toggle EN/AR at any time, everything switches including RTL layout
- **Procedural audio** — all sounds generated by Web Audio API, zero audio files
- **Persistent state** — game saves to localStorage, survive refreshes
- **Timer** — optional 30-minute countdown for pressure
- **Mobile-first responsive design** — fully playable on phones
- **Victorian aesthetic** — paper textures, corkboard, stamps, legal pad, typewriter fonts

## The Case: The Raven's Gate Affair

**Setting:** East London, November 1891

Lord Edmund Ashworth, 61, retired industrialist, found dead in his private study at Raven's Gate manor. Initial report: heart failure. But the examining physician noted an unusual pallor and the faint sweet-almond odour of prussic acid. The case was reopened.

**Suspects:**
- **Constance Hartley** — Personal secretary, managed the Whitechapel Widows' Relief Fund
- **Gerald Ashworth** — Son and heir, recently reconciled after estrangement
- **Mrs. Beatrice Rowe** — Housekeeper, three months unpaid wages
- **Dr. Silas Morrow** — Family physician, bound by a long-standing debt

**The conversation is the game.** One player explores 7 rooms across the manor, examining 18 clues and approaching characters. The other searches 6 archive entries, reads 4 documents, and builds connections on the case board.

## Development

### Adding a New Case

Create a new file in `src/data/cases/` following the `Case` type structure, then add it to `src/data/caseRegistry.ts`.

```ts
// src/data/cases/case_your_case.ts
import type { Case } from '../../types/game'

export const yourCase: Case = {
  id: 'your_case_id',
  title: 'Your Case Title',
  // ... full case data
}
```

### Build

```bash
cd client
npm run build
```

Zero TypeScript errors required before merging.
